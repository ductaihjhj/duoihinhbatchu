Hướng dẫn thêm hình ảnh cho game "Đuổi Hình Bắt Chữ"

Cấu trúc thư mục hiện tại:
- animals/ : Hình ảnh động vật
- fruits/ : Hình ảnh trái cây
- food/ : Hình ảnh đồ ăn
- nature/ : Hình ảnh thiên nhiên
- objects/ : Hình ảnh đồ vật

Để thêm ảnh mới:
1. Chuẩn bị hình ảnh (ưu tiên định dạng SVG hoặc PNG, kích thước khuyên dùng 400x300 pixel, phong cách cartoon dễ thương, màu sắc tươi sáng).
2. Đặt hình ảnh vào đúng thư mục chuyên mục.
3. Cập nhật dữ liệu game (ví dụ file JSON hoặc mảng dữ liệu trong mã nguồn) để trỏ đến tên file mới.

Lưu ý:
- Giữ tên file không dấu, phân cách bằng dấu gạch ngang (ví dụ: con-cho.png, qua-tao.svg).
- Các file SVG hiện tại chỉ là file giữ chỗ (placeholder), bạn có thể ghi đè chúng bằng hình ảnh chất lượng cao hơn.
