# 🎮 Game Đuổi Hình Bắt Chữ (Vietnamese Word Puzzle Game)

Game web "Nhìn hình đoán chữ" phong cách hoạt hình (Cartoon & Frosted Glass), đầy đủ tiếng Việt có dấu, âm thanh, hiệu ứng, và trang quản trị câu hỏi.

## ✨ Tính năng nổi bật
- **Giao diện Cartoon hiện đại**: Nền GIF chuyển động, hiệu ứng kính mờ (frosted glass), font chữ Be Vietnam Pro chuẩn Việt hóa 100%.
- **Icon chuyên nghiệp**: Hệ thống SVG icon Lucide sắc nét, tối ưu.
- **Tiếng Việt có dấu**: Hỗ trợ đầy đủ dấu thanh, dấu mũ chuẩn Unicode NFC.
- **Hỗ trợ gõ phím thông minh**:
  - Gõ Telex / VNI có dấu trực tiếp.
  - Gõ phím tiếng Anh không dấu tự động nhận diện chữ tương ứng.
- **Tính năng trợ giúp**: Gợi ý tự sửa ô sai, xóa nhanh, bỏ qua câu hỏi.
- **Trang Quản lý ẩn (`admin.html`)**: Thêm, sửa, xóa câu hỏi & hình ảnh, xuất file `data.js` dễ dàng.

## 🚀 Cách chơi
Mở trực tiếp file `index.html` bằng trình duyệt bất kỳ hoặc triển khai lên GitHub Pages!
